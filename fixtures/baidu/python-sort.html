Python 给列表排序主要有两种写法：直接用列表的 sort() 方法，或者用内置函数 sorted()，前者会把原列表改掉，后者会生成一个新列表。‌‌‌

什么时候用 sort，什么时候用 sorted

  1. ‌list.sort() 直接修改原列表‌：调用后原列表内容变了，返回值是 None，如果你不需要保留原顺序，用这个更省内存。
  2. ‌sorted() 返回新列表‌：原列表保持不变，生成一个新的已排序列表，适合还要保留原数据的场景。
  3. ‌对象范围不同‌：sort() 只能给列表用，sorted() 可以给列表、元组、字符串等任何可迭代对象用。‌‌‌

示例：

python
ums =
ums.sort()          # 原地排序，nums 变成
ums =
sorted_nums = sorted(nums)  # 原列表不变，sorted_nums 是

怎么控制升序、降序和按什么规则排

  1. ‌默认升序‌：不加参数时，数字按大小、字符串按字典序从小到大排。‌‌‌
  2. ‌降序排序‌：加 reverse=True 即可。
    • 示例：nums.sort(reverse=True)
  3. ‌按自定义规则排序‌：用 key 参数指定排序依据，常配合 lambda 函数。
    • 按字符串长度排：words.sort(key=len)
    • 按字典里某个值排：data.sort(key=lambda x: x['age'])
    • 按元组第二个元素排：pairs.sort(key=lambda x: x)‌‌7百科

示例：

python
words = ['banana', 'kiwi', 'apple', 'cherry']
words.sort(key=len)   # 按长度升序，结果 ['kiwi', 'apple', 'banana', 'cherry']
words.sort(key=len, reverse=True)  # 按长度降序，结果 ['banana', 'cherry', 'apple', 'kiwi']

排序时要注意的几个点

  1. ‌排序是稳定的‌：相同键值的元素，原来谁在前，排序后仍然保持原来的相对顺序。
  2. ‌类型要能比较‌：列表里混合了不能比较的类型（比如数字和字符串）会报错，排序前先统一类型。
  3. ‌特殊值要处理‌：None、NaN 等不能直接参与比较，需要先过滤或转换。‌‌‌
